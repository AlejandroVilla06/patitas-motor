# Patitas Motor

Clinical records engine for Patitas veterinary clinic, built with Node.js as part of Riwi's Algoritmia 2 track.

## Quick start

```bash
node pruebas/nodos.js
```

## Structure

```
patitas-motor/
├── src/
│   └── Nodo.js         # Node class (dato + siguiente)
├── pruebas/
│   └── nodos.js        # Manual node linking and traversal
├── bitacora.md          # Development log & diagrams
└── README.md
```
